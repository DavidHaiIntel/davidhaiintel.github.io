# שו"ת פתוח - IOC

אתר קטן לאיסוף שאלות (שם + שאלה) לקראת יום ההרצאה. השאלות נשמרות כ-Issues בריפו GitHub שלכם (כל שאלה = issue אחד), כך שהנתונים נמצאים אצלכם ב-GitHub, בחינם, עם היסטוריה מלאה.

- **עמוד ציבורי** (`index.html`): טופס שליחת שאלה + רשימת שאלות (מיון לפי חדשות/פופולריות + הצבעת 👍).
- **עמוד ניהול** (`admin.html`): התחברות בסיסמה אחת, עריכה/הסתרה (="מחיקה")/שחזור של כל שאלה. רק מי שיודע את הסיסמה יכול לערוך/להסתיר.
- "מחיקה" מבצעת סגירה (`closed`) של ה-issue - השאלה נעלמת לציבור אבל נשמרת ב-GitHub ואפשר לשחזר אותה.

## שלבי הקמה (חד פעמי)

### 1. יצירת ריפו ב-GitHub
צרו ריפו חדש (ציבורי או פרטי) והעלו אליו את הקבצים האלה.

### 2. יצירת Personal Access Token
ב-GitHub: Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
- Repository access: רק הריפו הזה.
- Permissions: **Issues: Read and write**.
- העתיקו את הטוקן (שורה ארוכה שמתחילה ב-`github_pat_...`).
⚠️ אל תדביקו את הטוקן בצ'אט או בקוד - הוא סוד.

### 3. פריסה ב-Vercel
1. היכנסו ל-vercel.com עם חשבון GitHub וייבאו את הריפו (New Project → Import).
2. לפני ה-Deploy, פתחו **Environment Variables** והוסיפו:
   | שם | ערך |
   |---|---|
   | `GITHUB_TOKEN` | הטוקן מהשלב הקודם |
   | `GITHUB_OWNER` | שם המשתמש/ארגון שלכם ב-GitHub |
   | `GITHUB_REPO` | שם הריפו |
   | `ADMIN_PASSWORD` | סיסמה שרק אתם יודעים |
   | `SESSION_SECRET` | מחרוזת אקראית ארוכה (אפשר להריץ בטרמינל: `openssl rand -hex 32`) |
3. לחצו Deploy. Vercel ייתן לכם כתובת כמו `https://your-project.vercel.app`.

### 4. שימוש
- שתפו את קישור העמוד הראשי (`/`) עם הקהילה.
- אתם נכנסים ל-`/admin.html` עם הסיסמה כדי לערוך/להסתיר שאלות.

## הרצה מקומית (אופציונלי, לבדיקות)
```
npm install -g vercel
vercel dev
```
וליצור קובץ `.env` מקומי (על בסיס `.env.example`) עם אותם משתנים - הוא לא נשמר ב-git.

## הערות אבטחה
- אין שום סוד בצד הלקוח - הטוקן והסיסמה קיימים רק בשרת (משתני סביבה ב-Vercel).
- כל קלט משתמש נחתך לאורך סביר ומוצג כטקסט בלבד (לא HTML) כדי למנוע XSS.
- יש שדה מלכודת-בוטים (honeypot) סמוי בטופס לצמצום ספאם.
